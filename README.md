## About Cisco Portfolio Navigator

Cisco Portfolio Navigator is designed to help teams organize product conversations, map account opportunities, and turn portfolio exploration into structured planning. It brings together visual graph-based navigation, guided workflows, and export-focused tools so users can move from discovery to a polished account plan without leaving the browser.

Built as a single-file HTML application, it is easy to open, share, and adapt for web-based use. The tool is especially useful for sales, solution, and planning workflows where clear structure, fast iteration, and presentation-ready output matter.

---

## Features

- Guided planning flow for structured account and portfolio work
- Interactive graph views for exploring relationships across the portfolio
- Account planner tools for organizing customer-facing strategy
- BYOK AI assistant support for assisted planning and content generation
- SVG stencil support for flexible visual building blocks
- Port-based linking to connect elements in a clear, diagram-like way
- Template gallery for quickly starting from reusable layouts
- Design score and suggestion engine for iterative refinement
- PoE tracking to help monitor progress across planning items
- Presentation mode for reviewing and sharing work cleanly
- Customer narrative export for moving from plan to client-ready output
